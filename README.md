# Aprilous — אתר המותג

Static website for Aprilous, the UV-C makeup brush cleaner. Hebrew, RTL, no build step.

- `index.html`: home page with an animated canvas "film" of the brushes spinning (wash → spin dry → UV-C → ready), how it works, gallery, reviews and FAQ
- `products.html`: product catalog with prices, filters, colour swatches, a comparison table and a cart drawer (saved in localStorage)
- `assets/css/style.css`: design tokens and all styles
- `assets/js/hero-film.js`: the hero animation
- `assets/js/main.js`: nav, scroll reveals, counters and cart
- `assets/img/*.svg`: product illustrations. Swap them for real product photos when you have them.

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).
